# RB Photography · Patras, Greece

Official website for **RB Photography** by Rami Babas. Capturing weddings, portraits, nature & wild places, and architecture across Greece and worldwide.

## Features

- **Editorial Luxury Design**: Bespoke Hatton serif typography, organic palettes, smooth scroll reveals, and sticky navigation.
- **Dynamic Media Configuration**: Easy photo/video swapping via [`media-config.js`](./media-config.js).
- **GitHub Pages Ready**: Static deployment directly from root via GitHub Actions (`.github/workflows/deploy.yml`).
- **React / TanStack Router Compatible**: Full TypeScript & TanStack Router setup in `src/`.
